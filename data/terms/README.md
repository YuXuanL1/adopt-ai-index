# Saved terms of use

For each row in `../sources.csv`, open its `terms_url` in a browser, select all the text
of the terms, and paste it into a plain-text file named `<source_id>.txt` here
(e.g. `seeking_alpha.txt`). Add the date you saved it on the first line.

Why by hand? The point of Part 1 is to read a site's terms *before* running scripts
against it - several of these sites ban automated access in those very terms.
