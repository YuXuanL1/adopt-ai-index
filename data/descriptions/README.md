# Hand-saved business descriptions

Firms that don't file a 10-K (Fidelity, Vanguard, TIAA, Nationwide, Betterment) need a
description for the Part 1.5 NLP step. For each, save 300-2,000 words describing what
the firm does into `<firm_id>.txt` (e.g. `vanguard.txt`), from the firm's own
"About us" page, annual report, or SEC Form ADV brochure (adviserinfo.sec.gov).
Put the source URL and date on the first line.

A file here overrides the 10-K text for a firm, so you can also use it to correct a
10-K whose "Item 1. Business" section isn't picked up well.
